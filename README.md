## File Structure

Preprocessing steps percentile, significance, and persistence calculations are performed in preprocess_ace2_era5.py, variance_calc.py, significance_calcs.py, persistence_fourcast.py, and quantile_ERA5.py. 
ACE plots are made via value_maps.py, fourcast/pangu plots are made via fourcast_era5.py, and climate change plots are made via wx_climate_change.py.
Supplemental figures for bias overtime are made in bias_over_time_plot.ipynb.
